🛡️ BEHIND CORAZA WAF SHIELD

Cổng Ứng Dụng Mẫu (Target Web App)

Ứng dụng web được bảo vệ bởi HAProxy Reverse Proxy + Coraza SPOA WAF

🔍 1. Truy cập Hợp Lệ (Clean Traffic)

Gửi yêu cầu HTTP bình thường không mang theo mã độc để kiểm tra tốc độ phản hồi 200 OK qua WAF.

Thử Truy Cập Hợp Lệ (200 OK)

💉 2. Test SQL Injection (SQLi)

Gửi payload thử nghiệm khai thác lỗ hổng cơ sở dữ liệu (UNION SELECT / OR 1=1).

Test Tấn Công SQLi (Sẽ bị 403)

⚡ 3. Test Cross-Site Scripting (XSS)

Gửi script chèn mã độc JavaScript (XSS Stored / Reflected) qua tham số URL query.

Test Tấn Công XSS (Sẽ bị 403)

📂 4. Test Path Traversal / LFI

Gửi payload duyệt thư mục trái phép đọc file hệ thống /etc/passwd.

Test Đọc File LFI (Sẽ bị 403)
Trạng Thái Hệ Thống: Đang hoạt động bình thường
Reverse Proxy: HAProxy 2.8+ Load Balancer
WAF Engine: Coraza SPOA (Stream Processing Offload Agent in Go)
OWASP Rule Set: Core Rule Set v4.9.0 + Custom Detection Signatures
