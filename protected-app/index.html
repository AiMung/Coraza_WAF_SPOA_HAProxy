HARDENED BY CORAZA WAF & HAPROXY

Cổng Ứng Dụng Mẫu (Protected Web App)

Hệ thống máy chủ ứng dụng web được bảo vệ an toàn tuyệt đối bởi Coraza SPOA WAF Engine & OWASP Core Rule Set v4.9

1. Truy cập Hợp Lệ (Clean Traffic)

Gửi yêu cầu HTTP thông thường không chứa mã độc. HAProxy & Coraza WAF sẽ cho phép đi qua và phản hồi HTTP 200 OK.

Thử Truy Cập Hợp Lệ (200 OK)

2. Test SQL Injection (SQLi)

Gửi payload thử nghiệm khai thác lỗ hổng SQL (UNION SELECT / OR 1=1--). Coraza WAF sẽ chặn ngay với 403 Forbidden.

Test Tấn Công SQLi (Bị 403)

3. Test Cross-Site Scripting (XSS)

Gửi script chèn mã độc JavaScript (<script>alert(1)</script>) qua URL query. WAF sẽ tự động chặn và ghi audit log.

Test Tấn Công XSS (Bị 403)

4. Test Path Traversal / LFI

Gửi payload duyệt thư mục trái phép đọc trộm file hệ thống (../../../../etc/passwd). WAF sẽ ngắt kết nối tức thì.

Test Đọc File LFI (Bị 403)
Reverse Proxy: HAProxy 2.8+ Load Balancer
WAF Engine: Coraza SPOA (Go Binary Engine)
Ruleset Defense: OWASP Core Rule Set (CRS v4.9.0)
Audit Stream: Real-time WebSocket & SQLite WAL
